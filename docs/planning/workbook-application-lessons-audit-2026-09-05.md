# Workbook and Apps Script lessons audit — 2026-09-05

## Scope

This capability audit uses the approved September workbook structure, the supplied helper,
the hardened helper candidate, current platform source/contracts, and focused automated tests. It
does not implement any recommendation. Google runtime behavior remains unverified.

Evidence labels are `PROVEN`, `CODE-VERIFIED`, `DOCUMENTED`, `INFERRED`, and `UNVERIFIED` as defined
in the local portability acceptance report. Classifications use only the five approved product
categories.

## Disposition

No workbook behavior is automatically scheduled from this audit. The only clear missing capability
is server-authored Account balance freshness; it should be scoped after Notifications because it
changes audit semantics. Reporting/KPI and residual formula workflows require a product decision
against the current roadmap. Spreadsheet row mechanics remain fallback-only. The current
Sportsbook-to-Free-Bet editor-entry smoke failure is also retained for later defect triage; it does
not change the conclusion that positional workbook copying should not replace the typed platform
workflow.

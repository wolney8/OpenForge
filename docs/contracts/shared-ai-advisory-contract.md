# Planning Contract: Optional Shared AI Advisory Layer

_Draft requirement reconciliation: 2026-11-27; issue #31. No provider call, external transmission, paid usage or runtime integration is approved._

The original optional fixture/player/racing context and its baseline/delta/source/confidence/fallback rules remain. A later shared adviser may explain Account access changes and residual value, summarise reviewed routines and task disposition, highlight stale/conflicting evidence and suggest transparent task ranking or routine/calendar drafts across Account, Today, offer review, ledger and Reports surfaces. Reuse one structured, Profile-authorised evidence/read model so pages cannot invent incompatible facts.

Every output separates (1) cited factual observation with as-of/source record, (2) deterministic eligibility, financial calculation and current rule-based queue, and (3) AI interpretation with uncertainty, missing evidence and a visible non-AI baseline/delta. One offer never proves full promotional restoration. Estimated opportunity is not realised or guaranteed profit. Claims about wager effects on account access require evidence. The user explicitly confirms any persistent routine, capability decision or financial action through its native command; AI never places or confirms bets or silently mutates Account, balance, P&L or risk state. Failure leaves the deterministic workflow available.

Decide before implementation: provider/model, allowed fields and Profile privacy minimisation, external search permission, structured evidence/output format, spend/rate limits, cache key/freshness, advisory audit/retention, prompt visibility and failure fallback. No credentials, sessions or raw owner workbook data may be sent. The smallest future tranche is opt-in cited explanations for a synthetic Account capability review and Today task using already approved stages 1–2 evidence; ranking weights and any financial recommendation require their own contract and fixtures. See the [cross-stage fixture spec](../fixture-specs/account-routine-event-advisory-fixture-spec.md).
